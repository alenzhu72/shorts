# Story Video Prompt Tool

Local MiniMax H3 story-to-video prompt tool.

## Run Locally

On Windows, double-click:

```bat
start-local.bat
```

Then open:

```text
http://127.0.0.1:8787/
```

Paste your MiniMax API key in the page before testing or generating videos. Use `api.minimaxi.com` if your key is from the Hailuo/MiniMaxi platform.

## Features

- Import or paste a story TXT file.
- Split by chapter or semantic segments.
- Generate Chinese or English summaries and MiniMax H3 video prompts.
- Upload up to 4 character reference images.
- Generate 1-5 ten-second vertical video clips per chapter.
- Query existing MiniMax task ids and recover MP4 links.
- Auto-save story text, settings, images, summaries, prompts, task ids, and returned video links in browser local storage.
